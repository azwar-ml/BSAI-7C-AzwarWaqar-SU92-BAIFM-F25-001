# Week 6 reproducible submission
Install the pinned requirements using the project virtual environment.
Run from this folder or pass each script path from the repository root.
1. Run `partA_process.py`: audit raw inputs and write clean data, decisions and audit.
2. Run `partB_charts.py`: export required static charts and notes.
3. Run `partB_analytics.py`: assert numerical anchors and export sensitivity metrics.
4. Run `partA_dashboard.py`: write offline interactive HTML and default PNG.
5. Run `partC_experiment.py`: export explicitly labeled automated checks; no fabricated trials.
6. Run `partD_figure.py`: export final 300 DPI dashboard.
7. Run `generate_partE_pdf.py`: write the one-page justification PDF.
